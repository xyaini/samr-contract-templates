# 全国合同示范文本库 · 全量下载

国家市场监督管理总局「合同示范文本库」（htsfwb.samr.gov.cn）全量下载存档，供个人学习与参考使用。

## 内容

- **合同 601 份**：部委 112 份 + 地方 489 份（32 个地区组）
- 每份合同两个版本：**Word**（.doc/.docx/.wps，可编辑）与 **PDF**（定稿排版）
- 共 **1202 个文件**

## 目录结构

```
dl/
  部委/<发文部门>/<合同名>.(doc|docx|wps|pdf)
  地方_<省份>/<发布机关>/<合同名>.(doc|docx|wps|pdf)
合同清单.md   # 全量索引（按地区 → 部门 → 合同名）
catalog.json  # 原始元数据（Id/标题/部门/地区/发布年份等）
```

## 单文件直链

每个合同也可从官方库直接下载：`htsfwb.samr.gov.cn/api/File/DownTemplate?id=<合同Id>&type=1|2`
（1=Word，2=PDF，请求需带 Referer 头）。

## 说明

合同示范文本供社会公众参照订立合同使用，条款理解与法律后果请参照相关法规；本仓库仅作存档镜像，更新以官方库 htsfwb.samr.gov.cn 为准。
